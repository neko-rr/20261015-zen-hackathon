## 機能比較表（必須）

Must 機能（idea またはユーザー指定）を行、競合を列:

| 機能 / Must | 自案 | 競合A | 競合B | 競合C | 出典 |
|-------------|------|-------|-------|-------|------|
| {Must 1} | 予定 | ○/△/× | | | [URL](...) |
| {Must 2} | | | | | |
| AI 活用 | | | | | |
| Web / Chrome | | | | | |
| ログイン不要 | | | | | |

記号: ○ あり / △ 一部・有料 / × なし / ? 未確認

|------|-------------|-------------------|-----------------|
| 体験 | | | |

## ハッカソン向け評価（簡易）

各競合に **審査員視点** で1行:

| 競合 | 強み | 弱み（我々の機会） | 3時間で追いつく？ |
|------|------|-------------------|------------------|
| | | | Yes / No / 不要 |

## MVP 示唆（必須セクション）

```markdown
## MVP 示唆

1. **真似する（表層）:** {例: 入力→生成の1画面フロー}
2. **簡略化:** {例: 履歴は1件だけ}
3. **逆張り / 差別化:** {例: 和風ビジュアル + 物理メタファ}
4. **やらない（競合にあるが Must 外）:** {例: SNS 共有}
```

## 品質チェックリスト

```
- [ ] 競合 3 件以上（focused）または 5 件以上（landscape）
- [ ] 各競合に URL + 確認日（YYYY-MM-DD）
- [ ] 未 Fetch の claim に {未検証} がある
- [ ] Must 機能が比較表の行になっている
- [ ] 差別化が「3分デモで伝わる」粒度
- [ ] 調査時間上限を超えていない（メタに記載）
- [ ] 秘匿情報・個人情報が含まれていない
- [ ] docs/ideas/*.md への転記提案（該当時）
```

## 判定フロー

```
Must 機能が主要競合すべてに ○
  → ニッチ化 or 体験差別化 or 案変更をユーザーに提示

Must の半分以上が空白（× が多い）
  → 実装価値高。差別化を1つに絞って進行

調査 15分経過 & 未完了
  → 現時点の結果で打切 → ideation へ
```
