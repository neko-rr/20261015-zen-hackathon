# 第5回のアイデア壁打ち

テーマ: 自律的に動く AI エージェントを、ガバナンスとセキュリティまで含めて使えるものにする。

公式: https://zenn.dev/hackathons/google-cloud-japan-ai-hackathon-vol5

ルールの確認は [gc-hackathon-vol5](../gc-hackathon-vol5/SKILL.md) と regulation-summary を使う。

## 姿勢

- 案を一度に並べない。質問は 1 つずつ
- 否定するときは、補強案をセットにする
- 作りきれない案、必須条件を満たさない案に時間を使わせない
- チャットで 1 回答えるだけの案は、エージェント案件として弱い。その旨を伝える

手順は [references/ideation.md](references/ideation.md)。
