# タスク同期 — 例

---

## quick モード（汎用）

**入力:** 「+90分時点。API 完了、UI 半分」

```markdown
## タスク sync (+90分)

- **区分 / 方式:** short / demo
- **次ゲート:** +120分 — 提出物確定
- **P0 残り:** 3件 — UI 完成、結合、サンプルデータ
- **今やること:** {Bob} UI、{Alice} API 結合
```

---

## gate モード（MVP ゲート超過）

```markdown
## ⚠️ ゲート超過

MVP 未達。提案:
1. P1 全延期
2. デモ用に UI を最小化
3. 次ゲートまでにローカル動作 → その後デプロイ

更新しますか？
```

---

## panic モード — demo 審査（例: 日記 × ビジュアル化アプリ）

**入力:** 「残り30分、間に合わない」

```markdown
| 残す | 削る |
|------|------|
| 1画面 + テキスト入力 + AI 結果1件表示 | 一覧、履歴、再生成、設定 |

理由: 3分操作デモで「入力→結果」が見えれば足りる
```

---

## panic モード — presentation 審査

```markdown
| 残す | 削る |
|------|------|
| デモ1フロー + 5分台本メモ | Nice 全機能 |

理由: 発表時間内に話せる量に合わせる
```

---

## plan → sync 流れ（short / 3h の例）

```
tasks-plan     → タスク表 + 方式 demo
+30min sync    → quick
+MVP gate sync → gate
提出前 sync    → gate
審査前 sync    → quick
```

半日・1日は milestones.md の頻度に従う。
