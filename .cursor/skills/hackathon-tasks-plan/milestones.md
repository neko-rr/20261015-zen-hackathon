# マイルストーン・制約

タスク計画・同期の共通参照。**プロジェクト doc から読み取り、推測で埋めない。**

## 収集チェックリスト

```
- [ ] 開発時間（何時間 / 開始〜審査まで）
- [ ] 開発開始時刻（分かれば絶対時刻を付与）
- [ ] 審査方式（操作デモ / プレゼン / 提出のみ / 未確認）
- [ ] 審査時間（1チームあたり）
- [ ] 成果物形式（Web / アプリ / 任意）
- [ ] チーム人数・メンバー名（AGENTS.md / tasks.md）
- [ ] デプロイ手順（AGENTS.md コマンド / infra/ / 未確認）
```

## 情報源

| 項目 | 読む場所 |
|------|---------|
| 開発時間・審査時刻 | `AGENTS.md`, `docs/tasks.md` タイムライン |
| 審査方式・提出物 | `docs/*-regulation-summary.md` |
| チーム | `docs/tasks.md` チーム表, `AGENTS.md` |
| デプロイ | `AGENTS.md` コマンド → `infra/` → `docs/infrastructure-*.md`（**任意**） |

## 開発時間の判定

doc に明記がなければユーザーに確認。

| 区分 | 目安 | キーワード例 |
|------|------|-------------|
| **short** | 〜4時間 | 3時間、半日未満 |
| **half** | 4〜8時間 | 半日、6時間 |
| **full** | 8時間〜 | 1日、24時間、オーバーナイト |

## 相対マイルストーン（開発開始 = 0）

### short（〜4時間）

| 経過 | ゲート | 完了条件 |
|------|--------|----------|
| +30分 | スコープ確定 | Must がタスク化・環境起動 |
| +50% | MVP ローカル | 核心機能が動く |
| 審査90分前 | 提出物確定 | URL / 成果物を demo-script に記録 |
| 審査30分前 | 審査準備 | 審査方式に合わせた確認完了 |

### half（4〜8時間）

| 経過 | ゲート | 完了条件 |
|------|--------|----------|
| +1時間 | スコープ確定 | 同上 |
| +50% | MVP ローカル | 同上 |
| 残り2時間 | 提出物確定 | 同上 |
| 残り1時間 | 審査準備 | 同上 |

### full（8時間〜）

| 経過 | ゲート | 完了条件 |
|------|--------|----------|
| +2時間 | スコープ確定 | 同上 |
| 午後開始前 | MVP ローカル | 同上 |
| 残り3時間 | 提出物確定 | 同上 |
| 残り1時間 | 審査準備 | 同上 |

**絶対時刻:** 開発開始時刻が分かれば、上記を `HH:mm` に変換して tasks.md に書く。

## P0 タスク数の目安

| 開発時間 | P0 目安 |
|----------|---------|
| short | 6〜10件 |
| half | 10〜15件 |
| full | 15〜25件（P1 は多めに可） |

## 1タスク粒度

- **30分以内** で完了できる単位
- 担当は **tasks.md / AGENTS.md のメンバー名**（未確定なら `{TBD}`）

## sync 頻度（tasks-sync 用）

| 開発時間 | 推奨 |
|----------|------|
| short | 30分ごと + 各ゲート前 |
| half | 1時間ごと + 各ゲート前 |
| full | 2時間ごと + 午前/午後境界 |

## ゲート判定（tasks-sync 用）

| 状態 | アクション |
|------|-----------|
| 次ゲートまで **30分未満** & P0 残り | P1 全延期 |
| 次ゲート **超過** & MVP 未達 | panic モード検討 |
| P0 全完了 | 提出物 + demo-script 最優先確認 |
