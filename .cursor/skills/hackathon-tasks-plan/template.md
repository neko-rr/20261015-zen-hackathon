## マイルストーンゲート

[milestones.md](milestones.md) の区分に従う。

```markdown
## マイルストーンゲート

| 目標 | ゲート | 完了条件 | 完了 |
|------|--------|----------|------|
| {HH:mm or +30分} | スコープ確定 | Must がタスク化済み | [ ] |
| {…} | MVP ローカル | 核心機能が動く | [ ] |
| {…} | 提出物確定 | URL/成果物を demo-script に記載 | [ ] |
| {…} | 審査準備 | {審査方式に応じた条件} | [ ] |
```

**審査準備の完了条件例:**

| 方式 | 完了条件 |
|------|----------|
| demo | 指定環境で操作フロー完走 |
| presentation | 発表時間内リハーサル完了 |
| submit | 提出物・期限確認済み |
