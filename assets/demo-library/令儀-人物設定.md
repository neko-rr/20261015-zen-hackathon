# 澄 令儀

皇帝 景衡の娘。20歳。璃京の澄書省で文書を裁く書令。実務家で、魔獣のときは王族の金光を扇から出す。愛用品は扇。

## 体

| 項目 | 指定 |
|------|------|
| 身長 | 168cm |
| 頭身 | 7.5 |
| 姿勢 | 背筋を伸ばす。重心は前に出すぎない |
| 手 | 指が長く、扇の要を常に親指で押さえる |
| 声の印象 | 低すぎない。文を短く切る |

## 顔

- 面長すぎない卵型。顎は細いが尖らせすぎない
- 目は大きめ、切れ長。虹彩は暗い茶。ハイライトは一点を大きく
- 眉は細く、やや上げて意志を出す
- 口は小さめ。普段は閉じる。歯は見せない
- 眉間に小さな朱の花片を一つ。盛装の花は足さない
- 女性向けライトノベルの塗り。肌は発光気味、頬に薄い紅

## 髪

漆黒。量は多い。頭頂で唐風の高い髻を作り、金の扇型の笄で留める。残りは背中へ下ろし、腰まで届く。前髪は顔を隠さない。毛先に細いハイライト。

## 服の重ね

1. 肌着は見せない
2. 象牙色の齐胸裙。上端に細い朱の帯
3. 墨色の半臂。肩の線をきれいに出す
4. 象牙色の袖。幅は広すぎない
5. 透明感のある披帛。縁だけ朱の一本線。膝のあたりまで
6. 黒地に金の縁取りがある、先が少し反った靴

アクセサリは笄と小さな真珠の耳飾りだけ。

## 扇

正扇は白地、縁に細い朱、骨は黒檀。仕事中は閉じている。考えるときだけ、閉じた扇の先を顎の手前で止める。口を隠すのは、言葉を飲んだときだけ。

私用の扇は墨一色で、資料用。正装の画面では白扇。

## 戦闘

文官の姿勢のまま戦う。膝を落とした構えや、鎧は描かない。魔獣の前では白扇を開き、黒檀の骨に沿って細い金光を走らせる。光は直線で、扇の先から闇の外縁をほどく。閉じた扇からは出さない。扇を棍棒のように振らない。

光の色は衣装の鈍い金と分ける。芯は #FFF8E7、縁は #F6E7A8。髪と服の色は変えない。

## 性格を絵にすると

- 相手の顔より、文書と扇を見ている時間の方が長い
- 微笑は口角だけ。目は仕事のまま
- 怒りは眉を寄せず、扇を一度だけ閉じる音にする
- 照れや甘えは描かない

## 表情資料の順番

左から右、上段から。

1. 無表情。職務の待機
2. 口角だけの微笑
3. 思案。閉じた扇を顎の手前
4. 決裁。閉じた扇を軽く前へ
5. 静かな怒り。目だけが冷える
6. 驚き。口は小さく開く
7. 扇で口元を隠す。言葉を飲んだ直後
8. まれな本音。目も少し和らぐ

表情資料の笄は簡略になっている。髪飾りの正は三面図の扇型。

## 描かない

大きな涙、腕組みの現代ポーズ、扇を棍棒のように振る、閉じた扇から光を出す、髪を黒以外にする。
