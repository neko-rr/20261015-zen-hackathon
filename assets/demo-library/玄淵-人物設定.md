# 澄 玄淵

皇帝 景衡の弟。34歳。親王。令儀の叔父。表向きは祭礼と文化の庇護者。実際は人事の配置を握る。魔獣のときは、袖の中の掌から王族の金光を出す。

## 体

| 項目 | 指定 |
|------|------|
| 身長 | 181cm |
| 頭身 | 8 |
| 姿勢 | 肩の力を抜く。令儀より半歩後ろ |
| 手 | 普段は広い袖の中。出すときは指が長く、力まない |
| 声の印象 | 柔らかい。文の終わりだけが少し低い |

## 顔

- 面長。鼻筋が通る。顎はシャープだが暴君にはしない
- 目は細め、狐に近い。虹彩は深い青灰。ハイライトは小さく、暖かくしない
- 眉は落ち着いている。片眉だけをわずかに上げることがある
- 口は美しい。微笑は左右対称で、歯は出さない
- 女性向けライトノベルの美形。ただし色気は温度が低い

## 怖い微笑の作り

口角だけを上げ、目は笑わせない。目尻の皺を足さない。下まぶたを上げすぎない。微笑が整いすぎているほど冷える。怒りもこの微笑のまま、目の光だけを消す。

## 髪

深みのある青。黒にしない。色は #1B3A6B を基準に、光が当たった筋だけ #3E6AA8。腰の上まで。頭頂で半分を小さな金の冠にまとめ、残りは背中へ下ろす。幞頭は被せない。

## 服の重ね

1. 白い内襟が見える円領
2. 深藍の袍。踝まで。雲の刺繍は襟と袖口だけ。金は鈍くする
3. 袖は広く、手を隠す
4. 袖の内側にだけ暗い赤の裏地。普段はほとんど見えない
5. 暗い革の帯。淡い緑の玉を三枚
6. 黒靴
7. 右手の親指に、外は鈍い金、内面だけ細い朱の環

## 性格を絵にすると

- 先に微笑んでから話す
- 令儀の扇を見ることがある。自分は扇を持たない
- 立ち位置は常に半歩後ろ。前に出るときは、相手の斜め後ろから回る
- 親切な顔と、目の温度が違う

## 戦闘

袍のまま戦う。剣は持たない。広い袖の中で掌に金光をため、袖口から細い曲線で出す。令儀の直線より遅く、闇が逃げる側を閉じる。微笑は消さない。目の温度だけを下げる。

光の色は令儀と同じ。芯 #FFF8E7、縁 #F6E7A8。刺繍の鈍い金 #C6A15B は光らせない。髪は深い青のまま。

## 表情資料の順番

左から右、上段から。

1. 公の微笑。まだ目に温度が残る
2. 腹黒の微笑。口だけ。目が冷たい
3. 心配のふり。眉は寄せるが目は笑っていない
4. 低い声。微笑を少し閉じ、視線を落とす
5. 含み笑い。口は閉じたまま頬が動く
6. 無表情の圧。微笑を消した状態
7. 目だけが細い愉悦
8. 令儀の白扇を見ている横顔

上段の左から2番が、この人物の基準の微笑。絵の目がまだ優しいときは、ハイライトを小さくして温度を下げる。本文の目の指定を優先する。

## 描かない

歯を見せた笑い、大声の怒り、髪を黒や銀にする、令儀に触れる、刃物を持つ、刺繍そのものを光らせる。
