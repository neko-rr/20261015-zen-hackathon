# 衣装と小物

彩色は女性向けライトノベル。布は絹。金属は鏡面にしない。金は鈍い。

## 令儀のレイヤー

外側から見える順。

1. 披帛（象牙、朱の縁）
2. 墨の半臂
3. 齐胸の裙（象牙、上端の朱）
4. 閉じた白扇
5. 扇型の金の笄
6. 真珠の耳飾り

白扇を開いた面は無地。絵を描き込まない。朱は縁の線だけ。魔獣のときだけ、骨に沿って金光を足す。扇面そのものは光らせない。

## 玄淵のレイヤー

1. 深藍の円領袍
2. 襟と袖口の鈍い金の雲
3. 袖裏の暗い赤（チラ見せ）
4. 三枚の淡緑の玉帯
5. 小さな金冠
6. 親指の環（外面は金、内面は朱）

## 小物資料の順番

絵の左から。

1. 正扇を閉じた状態。白地、黒檀
2. 正扇を開いた状態。面に絵は描かない
3. 扇型の金の笄
4. 私用扇。墨一色で開いた状態
5. 玉帯。淡緑の板が三枚
6. 親指の環。絵では外面の金。内面の朱は横から足す
7. 黒漆の印匣
8. 披帛の端の金の重り
9. 香印。扇を細くした形

## 素材メモ

| 物 | 素材 | 光 |
|----|------|----|
| 裙・袍 | 絹 | 広い面で柔らかく光る |
| 披帛 | 薄絹 | 背景が透ける |
| 扇骨 | 黒檀 | 光沢は細い線 |
| 玉 | 翡翠に近い淡緑 | 中が少し曇る |
| 冠・笄 | 金 | 磨きたてない |
| 印匣 | 黒漆 | 縁だけ金 |

背景の役人がいる場合だけ、黒い幞頭を使ってよい。主人物には使わない。
