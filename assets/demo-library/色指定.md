# 色指定

見本は `色見本.png`。画面の光で前後してよい。基準はこの番号。

## 共通

| 名前 | 番号 | 用途 |
|------|------|------|
| 紙 | #F6F1E8 | 資料の背景 |
| 肌・令儀 | #F6D3C4 | 暖色の発光 |
| 肌・玄淵 | #F0D2C6 | 令儀より少し冷たい |
| 朱 | #C23A2E | 一点だけ。花片、扇の縁、帯、環の内側 |
| 鈍い金 | #C6A15B | 笄、冠、刺繍。光らせない |
| 金光の芯 | #FFF8E7 | 王族の魔法。扇の骨と掌 |
| 金光の縁 | #F6E7A8 | 金光の外側。絹糸のように細い |
| 闇 | #1A1424 | 魔獣を纏う闇の地 |
| 闇の縁 | #3A3148 | 闇のほつれ |

## 令儀

| 名前 | 番号 | 用途 |
|------|------|------|
| 黒髪 | #1A1214 | 地の色 |
| 黒髪の光 | #5C4A52 | 毛先のハイライト。青にしない |
| 象牙 | #F4EFE4 | 裙、袖、披帛 |
| 墨 | #2C2422 | 半臂、靴 |
| 扇の白 | #F7F4EE | 扇面 |

## 玄淵

| 名前 | 番号 | 用途 |
|------|------|------|
| 深藍 | #1B3A6B | 髪と袍の地 |
| 青の光 | #3E6AA8 | 髪のハイライト |
| 袍の影 | #152848 | 袖の折れ |
| 裏地 | #6E1E2A | 袖の内側だけ |
| 革 | #3A2A22 | 帯 |
| 玉 | #8FB39A | 帯の板 |
| 目 | #4E6278 | 青灰。暖色の茶にしない |

朱を玄淵の衣装の表面に広げない。赤は裏地と環の内側だけ。

金光は魔獣の場所以外に置かない。衣装の金とは別の色。
