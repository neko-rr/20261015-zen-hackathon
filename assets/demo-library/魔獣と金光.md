# 魔獣と金光

平時の澄洲は、文書と人事の宮廷。魔獣が出たときだけ、王族が金色の光を使う。絵は女性向けライトノベル。血と断裂は描かない。見本は `魔獣と金光.jpg`。

見本では、令儀の開いた扇から出る金光が一番はっきりしている。玄淵の光は袖口から、扇の光と絡まないもう一本の曲線として足す。魔獣は顔を作らず、闇の布が低い獣の形でほどける。

## 誰が戦えるか

令儀と玄淵は、文官の仕事をする王族で、戦闘もできる。服は平時と同じ。鎧も剣も持たない。

金光を出せるのは王族だけ。皇帝 景衡も出せるが、この資料の主人物にはしない。臣下、兵士、同じ扇を借りた役人には出ない。

## 金光

| 項目 | 指定 |
|------|------|
| 使える人 | 王族だけ |
| 効く相手 | 闇を纏った魔獣だけ |
| 芯 | #FFF8E7 |
| 縁 | #F6E7A8 |
| 太さ | 絹糸から、扇の骨ほどの帯まで |
| 衣装の金 | #C6A15B のまま。光らせない |

令儀は白扇を開いたとき、骨に沿って直線の光を出す。扇面に紋は描かない。閉じた扇からは出さない。

玄淵は袖の中の掌に光をため、袖口から曲線で出す。微笑は残す。

二人の光は絡めない。令儀が闇の正面をほどき、玄淵が逃げる側を閉じる。建物や人には火が移らない。光が触れるのは、魔獣を纏う闇だけ。

## 魔獣

闇を布のように纏った獣。中の形は、低い四足がおぼろげに見える程度。顔は作らない。目は描くなら、光が当たるまで濁った金で、当たったあと消える。

| 項目 | 指定 |
|------|------|
| 地の闇 | #1A1424 |
| ほつれた縁 | #3A3148 |
| 大きさ | 令儀の肩から、玄淵の頭の高さまで |
| 倒し方 | 王族の金光だけ。矛は通過する |
| 倒れ方 | 闇が糸くずのようにほどける。死体は残さない |

牙、血、内臓、虫の群れは描かない。可愛い使い魔にもしない。

## 一日の描き分け

- 机の前では金光を出さない。扇は閉じるか、考えるための位置
- 廊に闇があるときだけ、扇を開き、袖口を光らせる
- ほどけたあとは、二人とも服の乱れを小さく直し、文書の話に戻る

## 描かない

王族以外の手から金光を出す、炎や雷に置き換える、剣で斬って倒す、光で人を焼く、魔獣をペットとして傍らに置く。
