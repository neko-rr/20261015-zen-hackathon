## 動作確認の方法

メールは使わない。審査は共有のテストアカウントで入る。一般のアカウントは人ごとに分かれる。

貼る文:

```text
1. 作品URLを開く。
2. ログインする。メールや Google へのログインは不要。パスワードは画面とリポジトリに出さない。
3. サンプル写真を開く。物体の層、マスク、骨格、筋肉、3D人形を切り替える。
4. 写真が無いときは、入力欄に「座っている人」と入れて人形を出す。絵は生成されない。
5. 物体を選び、題名か作者が分かるときだけ調べる。出典URLが付き、ライセンス等がページに無ければ「未確認」のまま残る。
6. OSS の表記は同じサイトの /licenses を開く。
7. API の死活は {APIのURL}/health が開けることで確認する。

審査用 reviewer は審査員の共有です。自分用に残すときは「アカウントを作る」で別のユーザー名を作ってください。そのアカウントのデータは他の人と混ざりません。
```

作品URLと API の URL は、提出フォームに書くときに実アドレスへ置き換える。このファイルには固定しない。
