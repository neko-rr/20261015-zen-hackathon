## 参加条件

- チーム構成: 個人または個人で構成されるチーム。チームは代表者・メンバー全員の参加登録が必要
- 資格: 日本国内に居住する 18 歳以上。Google Cloud Innovators への参加は不要。スキル条件なし
- 参加できない人: 政府機関の職員（非常勤・兼業を含む）、企業代表として選出された個人、スポンサーおよび主催者の従業員とその関係者・家族、企画運営に直接関与する者、主催者が不適切と判断した者
- 申込: Zenn ログイン後にエントリー → Google フォーム。チームは代表者がプロジェクトを作り、メンバーを招待
- メンバー追加・脱退: 2026-10-15 23:59 まで（提出後も締切までは可）
- 参加費: 公式ページに記載なし（未確認）
- 費用: Google Cloud 利用料は自己負担。エントリー者に 300 ドル分クーポン（数に限りあり。クレジットカード登録が必要。再発行なし）
