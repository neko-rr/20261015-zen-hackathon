## 作品レギュレーション

| 項目 | 内容 | 出典 |
|------|------|------|

| Gemini API の利用場所 | AI Studio からの直接利用でも AI 条件は満たす。実行プロダクトの利用は別途必須 | 公式ページ（FAQ） |
| Firebase 経由の Gemini API | AI 条件を満たす | 公式ページ（FAQ） |
| 任意（提出フォームで知らせる） | Flutter、Firebase | 公式ページ（ルール） |
| Support スポンサー技術 | 駅すぱあと API MCP サーバー、YouCam API、GMI Cloud。利用有無は審査に影響しない | 公式ページ（ルール） |
| アプリ形態 | Web でもネイティブでも可。実行プロダクト条件は満たすこと | 公式ページ（FAQ） |
| ネイティブの URL | 可能な限り Web 版の URL。難しい場合は「動作確認の方法」に事情を書く | 公式ページ（FAQ） |
| デプロイ | Google Cloud へのデプロイが必要。ローカルのみは不可。dev 環境でも、動作確認できれば可 | 公式ページ（FAQ） |

| リポジトリの中身 | 主要機能がモックではなく実装されていることが分かる範囲。どの部分を開発し、どこがパッケージかを説明する | 公式ページ（FAQ） |
