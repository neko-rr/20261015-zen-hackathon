# 審査用デモ確認シート

> 審査方式は [レギュレーション要約](google-cloud-japan-ai-hackathon-vol5-regulation-summary.md) から転記。提出審査はリモート。登壇用の台本ではない。

## 審査方式（要約から転記）

| 項目 | 内容 |
|------|------|
| 方式 | 提出物とデプロイ URL を審査員がリモートで確認。ネイティブのみの場合はデモ動画中心 |
| 時間 | デモ動画は約3分。最終ピッチ（2026-12-01）の持ち時間は未確認 |
| プレゼン | 提出時の登壇は記載なし。ファイナリストは最終ピッチがある |
| 提出物 | GitHub 連携、デプロイ URL、説明文、アーキテクチャ図、YouTube デモ動画 |

## 審査前チェック

- [ ] デプロイ URL が審査環境で開ける
- [ ] 動作確認の方法に「URL を開き『はじめる』（または自動開始）→ サンプル写真」と書いてある。メール／Google ログインは無い
- [ ] ソーシャルログイン、メール受信必須のログインになっていない
- [ ] 共有デモアカウントや、審査員同士で履歴が混ざる設計になっていない
- [ ] 約3分の動画で、対象ユーザー・課題・エージェントの動作が分かる
- [ ] 主要機能がモックではない
- [ ] 2026-12-01 まで URL とデフォルトブランチを維持できる

## 操作フロー（審査員視点）

| 順 | 操作 | 見せたいポイント | 完了 |
|----|------|----------------|------|
| 1 | URL を開き「はじめる」（セッション開始）。サンプル写真を開く | 登録なし。自分のセッションだけ | [ ] |
| 2 | 元画像／マスク／骨格／筋肉／3D を切り替える。3D はドラッグで回転 | 輪郭に沿った観察。姿勢と体積。絵は生成しない | [ ] |
| 3 | 選んだ物体を調べ、出典とライセンス履歴を開く | URL・時期・著作権。不明は未確認のまま | [ ] |

### 余力（時間があれば）

| 順 | 操作 | 見せたいポイント | 完了 |
|----|------|----------------|------|
| A | `/library` で自作／他者を登録し、案件・タグを付ける | 人手の分類。AI 自動分類はしない | [ ] |
| B | Studio で使うタグ／案件を選び、もう一度調べる | 手元 RAG にタグが効く | [ ] |
| C | 出典をピン・メモし、制作ログを書き出す | セッション内。クラウド永続しない | [ ] |
